# Numpy

#README intro:

**NumPy Practice**

A collection of Python scripts and notebooks I wrote while learning NumPy, the core library for numerical computing in Python. It covers the fundamentals through to more applied operations, with short explanations and runnable examples.

**Topics covered**

Array creation, shapes, and data types
Indexing, slicing, and boolean masking
Broadcasting and vectorized operations
Reshaping, stacking, and splitting arrays
Mathematical and statistical functions
Linear algebra (dot products, matrix operations, inverses, eigenvalues)
Random number generation

**Tech stack**

Python, NumPy (plus Jupyter Notebook, if you use it)
